# TRIZNES — система «Ядро» (Launch UI v1)

LIFE CINEMA OPERATING SYSTEM. Не SaaS, не CRM, не соцсеть. Каждый экран проходит проверку: «если убрать логотип — это всё ещё TRIZNES?»

## Принципы
- **Человек в центре.** Реальный человек визуально важнее AI. Лица никогда не генерируются и не берутся со стоков. Нет фото → нейтральная рамка `MediaFrame` / инициалы `Avatar`.
- **Ядро в центре.** `CoreEmblem` (треугольник + глаз + ядро) — главный символ. Максимум один крупный на экран; в остальных местах — иконка `TriznesCore`.
- **Progressive disclosure.** Ядро → главные направления → детали. За 2 секунды: где я, что главное, что происходит, что можно сделать.
- **Язык мира**, не корпоративный: персонаж, роль, сцена, импульс, глава, путь, связь, мир. Никаких «сотрудник / workflow / KPI».
- **Одно следующее действие.** На экране одна главная CTA (`Button` primary). Остальное — secondary / ghost. Голос BEZLIKI: «Сейчас важно только это» + одна кнопка.

## Цвет
- Основа: `neutral-0` фон; панели — стекло `glass-surface` + `glass-border` + backdrop-blur. Сильное стекло (`glass-surface-strong`, `glass-border-strong`) — активное/наведение.
- Сапфир `brand-*` — энергия ядра, активные состояния. Градиент `brand-500 → accent-pink` — только главная CTA и центральная «+».
- `accent-cyan` — «живое / сейчас», эйброу-метки. `accent-pink` — PINK NOIZE и съёмки, точечно. `accent-violet` — сообщества и генерации.
- Статусы: `success` — онлайн/готово; `warning` — задержка; `error` — блокеры; `special-gold` — только ADMIN, GOLD-карта, премьера.
- Неон дозирован: свечение — мягкий blur; без жёстких неоновых обводок, glitch и сеток-подложек (исключение — едва видимая точечная сетка на досках).

## Происхождение материалов
Каждый медиа-объект помечается `origin`: **REAL** (белый) · **AI ASSISTED** (cyan) · **GENERATED** (violet) · **ARCHIVE** (сепия). По умолчанию для людей — REAL.

## Форматы медиа (`MediaFrame`)
portrait 3:4 · landscape 16:9 · vertical 9:16 · square 1:1 · poster 2:3 · audio 4:1 (волна) · document 3:4. Композиции строятся под эти пропорции, поэтому реальные материалы вставляются без перестройки. Состояния: default · loading · empty («Добавить материал») · locked.

## Типографика (Inter)
`display-xl` 96 — только hero входа/ядра · `display` 64 — названия фильмов/персонажей в hero · `heading-1/2/3` — разделы · `body` 15 · `caption` 13 · `eyebrow` 11 uppercase, трекинг 0.28em — метки разделов. Кириллица — основной язык.

## Радиусы и глубина
`corner-md` 12 — элементы списков · `corner-lg` 20 — карточки и панели · `corner-xl` 28 — крупные сцены, нижняя панель · `corner-full` — кнопки, чипы. Тени: `elevation-panel` — плавающее; `glow-brand` — главная CTA/выбранное; `glow-core` — только ядро.

## Состояния интерактивных элементов
default · hover (подъём −4px, `glass-border-strong`, мягкое сапфировое свечение) · active/selected (кольцо `brand-500` + `glow-brand`) · loading (световой проход) · empty (пунктир + действие) · success · warning · locked (60% прозрачности + замок).

## Адаптив
| Точка | Ширина | Поведение |
|---|---|---|
| Desktop | ≥1440 | полные композиции, `SidebarNav` 232px + `TopBar` 64px |
| Laptop (`laptop:`) | 768–1439 | двухколоночные ряды складываются в одну колонку, сайдбар остаётся |
| Mobile (`mobile:`) | ≤767 | отдельный игровой пульт: компактная шапка, `MobileTabBar`, горизонтальные свайп-ленты, нижние шторки вместо боковых панелей |
| Phone (`phone:`) | ≤430 | телефон (390–430): всё в одну колонку, строки с действиями переносят кнопки под текст, ничего не обрезается по ширине |

Стили desktop-first: без префикса — desktop, `laptop:` действует ≤1439 (включая mobile), `mobile:` — ≤767 (включая phone), `phone:` — ≤430.

## Навигация
- **Desktop:** `SidebarNav` (группы МИР · СОЗДАНИЕ · СИСТЕМА) + `TopBar`.
- **Mobile:** `MobileTabBar` — Я · МИР · + · КИНО · ЯДРО. «+» раскрывает: Снять · Загрузить · Идея · Событие · Человек · Сцена.
- **РАЙ / CYBER** — два визуальных слоя одного мира (в `TopBar` и на карте).

## Логика анимаций (для кода)
Анимация усиливает смысл, а не демонстрирует эффекты. Всё отключается при `prefers-reduced-motion`.

| Эффект | Где | Параметры |
|---|---|---|
| Дыхание ядра | `CoreEmblem`, текущий `TimelineNode` | scale 1→1.12, opacity .75→1, 5.5s ease-in-out, бесконечно |
| Пульс «сейчас» | активный `MapMarker`, точки онлайн | кольцо scale 1→1.8, opacity .4→0, 2.4s |
| Подъём карточки | Character / Film / Media карточки | translateY −4px, 250ms cubic-bezier(.2,.8,.2,1) |
| Свет портала | плитки действий | свечение снизу scale 1→1.08, 300ms на hover |
| Протягивание связи | граф, путь, доски | stroke-dashoffset 100%→0, 600ms ease-out |
| Световой проход | loading в `MediaFrame` | диагональная полоса, 1.6s linear |
| Дрейф частиц | фон ядра, вход | очень медленно (30–60s), 3–6 частиц, opacity ≤ .3 |
| Параллакс | hero входа | слои ±8px от курсора / гироскопа |
| Кинопереход | смена экранов | fade + blur 8px→0, 400ms |
| Раскрытие «+» | `MobileTabBar` | веер 6 кнопок, stagger 30ms, «+» поворот 45° |

## Известные ограничения v1
- `MediaFrame` в очень маленьких превью (< ~80px) показывает подпись формата тесно — в коде скрывать подпись на мелких размерах.
- Тема в Subframe помечена как «light», хотя значения тёмные; отдельного светлого режима нет. «РАЙ» пока визуальный переключатель, не тема.
