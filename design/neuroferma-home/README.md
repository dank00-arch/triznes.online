# Нейроферма TRIZNES — новый главный экран (дизайн-передача)

Дата: 2026-10-28 · Источник: проект Subframe `triznes.online`, канвас «Нейроферма — главный экран».

Это **макеты**, а не рабочий код сайта. Папка ничего не меняет на живом сайте.

## Что внутри

| Файл | Что это |
|---|---|
| `screens/yadro-desktop.png`, `screens/yadro-mobile.png` | Вариант A «Ядро — центральный портал» |
| `screens/kino-os-desktop.png`, `screens/kino-os-mobile.png` | Вариант B «Кино-ОС — студия-пульт» |

Скриншоты десктопа сняты на ширине 1100px (рассчитано на 1440px), мобильные — на 767px.

## Задача для реализации

Сайт — статический HTML + vanilla JS (`neuroferma-app.html`, `neuroferma-app.js`, Supabase). React-код из `code/` **не подключать напрямую** — использовать как точную спецификацию разметки, отступов и цветов и перенести в HTML/CSS проекта.

Жёсткие ограничения:
- Не менять Supabase, авторизацию, роли, permissions, API, маршрутизацию, данные, генераторы и интеграции.
- Не удалять существующие функции (очередь ревью видео, одобрение, правки — остаются).
- Работать только с визуальным слоем и UX.
- Не заменять реальные фото людей AI-лицами. В макетах у персонажей — плейсхолдеры с инициалами: туда идут настоящие фото.
- Демо-данные в макетах (проекты «Сочи 2049», «Ночной экспресс», «Голос моря», проценты, очередь) — заглушки; в коде брать реальные данные, где они есть.

## Структура экрана (оба варианта)

1. Верхняя панель: поиск, статус «Движок онлайн · N в очереди», уведомления, аватар.
2. Боковое меню (десктоп): Нейроферма, Пульт, Персонажи, SOCHIWOOD, Сообщества, Квесты, Карты, Архив, Мои проекты. На мобильном меню скрыто — нужна нижняя таб-панель или бургер.
3. Hero: «ЖИЗНЬ В ИГРЕ» / «НЕЙРОФЕРМА TRIZNES» / «Создавай свой мир», кнопки «Создать» и «Продолжить проект».
4. Порталы создания (6): Создать видео (Runway · Kling), Создать изображение, Создать музыку / звук (ElevenLabs), Создать персонажа, Собрать фильм (Creatomate · OpusClip), Продолжить проект (прогресс).
5. Активные проекты / фильмы и сцены — карточки со статусом и прогрессом.
6. Последние генерации — сетка медиа со статусами (Готово / Генерация % / Нужна правка).
7. Персонажи — портреты + «Новый персонаж».
8. Очередь производства — задачи с инструментом, прогрессом, ETA, статусом.
9. «Производственный движок TRIZNES» — ядро с подключёнными модулями (Runway, Kling, ElevenLabs, Creatomate, OpusClip, Нейро-кадр), а не список сервисов.

Отличия вариантов:
- **A «Ядро»** — симметричный hero с треугольником и светящимся ядром, 6 порталов в ряд, ниже две колонки (контент | очередь + движок).
- **B «Кино-ОС»** — hero слева + панель движка справа на первом экране, порталы bento-сеткой, затем «Сейчас в производстве». На мобильном панель движка стоит до порталов — при реализации поставить её после порталов.
