# DIRTY PARADISE: SOCHI IN THE GAME
**Роль:** первая кинематографическая игровая вселенная TRIZNES REALITY ENGINE.

## Позиционирование
DIRTY PARADISE — не отдельная игра и не новый профиль игрока. Это сезон/сценарная вселенная общего TRIZNES LIFE GAME. Игрок использует свой существующий CHARACTER, карту, главы, квесты, связи и медиаархив. Сценарий добавляет особую драматургию, эстетику и AR-события.

## Визуальный канон
- CYBER NIGHT: #FF35C8, #42ECFF, #CAFF39, #07040B; мокрые отражения, дымка, лазерные объёмы, субтропики.
- ABUNDANCE DAWN: золото, персик, бирюза, мягкий морской свет.
- Оптика: фотореализм, anamorphic 35mm look, естественная кожа, лёгкое зерно и halation.
- PINK NOIZE — авторский звуковой мир; синхронизация света и AR с ритмом по доступным аудиоданным.

## Проводники
1. Маэстро Бриза — федора с бирюзовой лентой, очки, белая рубашка, арт-брюки.
2. Неоновый Архитектор — чёрная рубашка с неоновыми линиями, очки на лбу, золотой дух игры на ладони.
3. Золотой Страж — золотая филигранная маска, чёрный объёмный пуховик, золотая цепь.
4. Кислотный Алхимик — панама, лайм-пурпурный камуфляж, изумрудный фейс-арт, красные очки.
5. Кибер-Макака — неоновый ирокез, бирюзовые биотатуировки, жилетка, золотые серьги.
Проводники — сценарные роли. Подстановка конкретных реальных людей возможна только при наличии подтверждённого профиля, согласия и соответствующего образа.

## Контур AI Director
- Понимает текущего персонажа, главу, уровень, место, согласия и режим.
- Принимает чат-команду, определяет intent, проверяет безопасность и права.
- Возвращает типизированное событие, а не произвольный исполняемый код.
- Может предложить визуальную сцену и AR-объект; человек подтверждает события с воздействием на других людей, публикацию, геометки или постоянное изменение состояния.
- Отделяет быстрый AR-слой от более медленного V2V-ререндера.

## Технический pipeline
Camera/WebRTC → bounded frame buffer → V2V worker (StreamDiffusionV2/Wan) → identity/temporal QC → output stream.
Chat → LLM Director → JSON Schema validation → permission/safety gate → event bus → Three.js/WebXR AR compositor → Game State event log.
Оригинальный поток и нейросетевая производная хранятся/передаются раздельно; медиаархив остаётся в Google Drive/объектном хранилище, не в Supabase.

## Ограничения производительности
- Не фиксировать NOISE_SCALE=0.85 как универсальный закон; сделать адаптивный параметр с профилями движения и качества.
- FPS зависит от GPU, разрешения, модели, числа шагов, batching и сетевой задержки. Бенчмарк 91 FPS для image generation не доказывает live V2V 91 FPS.
- 1.3B — кандидат для первого теста; H100 — облачный benchmark target, не обязательное условие архитектуры.
- Если V2V не укладывается в бюджет задержки, AR остаётся интерактивным, а стилизация переключается в сниженное разрешение/частоту или post-process fallback.
- Identity Lock — измеряемая цель с fallback на оригинал, не абсолютная гарантия.
