# TRIZNES · содержание игры и платформы

Эти файлы содержат рабочие тексты и продуктовые правила, не дизайн-макеты и не юридические документы.

- [Манифест](manifest.md) — краткое и полное представление платформы.
- [Словарь мира](glossary.md) — значения интерфейсных терминов и границы авторства.
- [Маршрут участника](participant-flow.md) — вход, профиль, медиа и решение о публикации.
- [Игровой цикл](quest-loop.md) — первые добровольные действия и правила автоматизации.
- [Тексты экранов](screen-copy.md) — рабочие заголовки, CTA, empty/error states и отдельные согласия для девяти экранов.
- [Канон ядра и визуальная приёмка](../../launch-ui/CORE-VISUAL-CANON-2026-11-05.md) — режимы и визуальные ограничения.

### Обязательные метки перед реализацией

- `APPROVED`: подтверждённый факт, готов к интерфейсу.
- `WORKING COPY`: редакторский текст; показать владельцу до публикации.
- `NEEDS SOURCE`: требует источника данных/архива/автора.
- `NOT IMPLEMENTED`: обещать нельзя, пока функция реально не работает.

Не превращать текущий документ в источник персональных данных или согласий. Персональные факты брать из проверенного профиля, медиа — из разрешённого архива, функциональные статусы — из API.
