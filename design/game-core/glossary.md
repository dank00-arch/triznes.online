# Словарь мира TRIZNES

| Термин | Значение | Где используется |
|---|---|---|
| Ядро | Общие ценности и правила, соединяющие людей, идеи, места и истории | Все экраны |
| Персонаж | Реальный человек как автор собственной истории; не выдуманный AI-аватар | CHARACTER, CINEMA |
| Идея | То, что человек хочет выразить или создать | ENTRY, CHARACTER |
| Мечта | Желаемое направление пути, сформулированное самим человеком | ENTRY, CHARACTER |
| Роль | Добровольно выбранный способ проявляться в общем кино | CHARACTER, COMMUNITY |
| Сцена | Конкретный момент действия в реальном месте/времени или цифровом пространстве | SOCHIWOOD, QUEST |
| Глава | Большой этап личного пути; не должность и не оценка человека | HOME, CHARACTER |
| Уровень | Сценарный шаг внутри главы или отдельной игровой вселенной | QUEST, WORLD |
| Импульс | Идея/намерение, получившее ясный следующий шаг | PULT, NEUROFARM |
| Квест | Добровольное приглашение к действию с ясной целью и критерием завершения | QUEST |
| Проводник | Персонаж/участник, помогающий открыть новую оптику; не управляющий чужой волей | WORLD, CINEMA |
| Коллайдер | Пространство встречи идей, людей и действий, из которых возникает совместное творчество | COMMUNITY, CINEMA |
| РАЙ | Визуальный режим изобилия: свет, тепло, открытость, живые цвета | WORLD MAP |
| CYBER / GAME | Игровая оптика: неон, сигналы, квестовые знаки, цифровые слои | WORLD MAP, XR |
| DIRTY PARADISE | Первая кинематографическая игровая вселенная Сочи внутри TRIZNES | WORLD, CINEMA, REALITY |
| REALITY ENGINE | Связка физического города, камеры, AI-режиссуры, AR и состояния игры | XR / AR |
| Prompt-to-AR | Преобразование запроса в валидированное AR-событие | REALITY ENGINE |
| Identity Lock | Целевой контроль сохранения узнаваемости и мимики участника; не абсолютная гарантия | VIDEO ENGINE |
| Путь импульса | Производственный маршрут от идеи до подтверждённого архива/публикации | NEUROFARM |
| PULT | Интерфейс выбора следующего действия и управления игровым состоянием | MOBILE PULT |
| APOLLON | Тёплый вход и раскрытие идеи, мечты, состояния | ENTRY |
| DIONYSUS | Игровой проводник действия и трансформации | QUEST |
| BEZLIKI | Системный оператор и контекстный навигатор | PULT, CORE |
| BLACK | Личная карта персонажа | ENTRY, CHARACTER |
| SILVER | Карта места/сообщества/проекта | COMMUNITY, WORLD |
| GOLD | Клубная карта «За любовь» | COMMUNITY |
| Доказательство | Добровольно предоставленный артефакт выполнения шага; не слежка | QUEST |
| Событие игры | Типизированное изменение состояния мира, вызванное подтверждённым действием | GAME STATE |
| Общая история | Совместно создаваемая хроника людей, мест и сцен | SOCHIWOOD, ARCHIVE |
