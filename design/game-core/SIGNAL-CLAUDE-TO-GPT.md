## Что нужно от тебя (расширенный объём — по запросу Даниеля: «наполнить по полной»)
Помимо базового `GPT-CORE-BRIEF.md`, Даниель просит наполнить платформу **по полной: новости, контент, профили, сообщества и все идеи ядра**. Разложи это так:

### 1. Ядро смыслов → `manifest.md`, `glossary.md`
- Манифест TRIZNES в 3 длинах (1 строка / 3 строки / страница).
- 9 звеньев цепочки ядра — по фразе.
- Словарь мира: роль, сцена, импульс, глава, путь, связь, РАЙ/CYBER, Аполлон, Дионис, BEZLIKI, карты BLACK/SILVER/GOLD.

### 2. Игра и путь → `chapters.md`, `impulse-path.md`
- 6 глав пути персонажа (название, цель, переход, что открывается).
- **10 этапов пути импульса Нейрофермы** (названия 5–10 + критерий «этап пройден»).
- Прогресс карт BLACK → SILVER → GOLD.

### 3. Квесты → `quests.md`
- 10–15 стартовых квестов (главы 1–2) + 3–5 квестов сообщества.
- Квесты, привязанные к **реальным** местам Сочи (только существующие).

### 4. Контент мира → `world-content.md`
- **Новости/лента World Pulse**: форматы и шаблоны карточек (не выдумывать конкретные факты — дать структуру и редполитику; реальные новости берутся из ленты Сочи).
- **Сообщества**: описания Сочи · Театр ТУЗ · PINK NOIZE (что это, чем живут) — по реальным данным от команды.
- **Профили/персонажи**: шаблон описания (роль, идея, мечта) — без выдуманных реальных людей.

### 5. Качество медиа → `media-standards.md`
- Требования к кадру по форматам MediaFrame, правила меток REAL / AI ASSISTED / GENERATED / ARCHIVE, список медиа к съёмке по 9 экранам.

### 6. Креативная карта → `game-map.md` (Mermaid)
- Узлы (человек/идея/мечта/роль/место/сцена/фильм/сообщество) и переходы-глаголы; путь новичка ≤7 шагов.

## Жёсткие правила (общие с дизайном)
- **Нельзя выдумывать реальных людей и факты.** Реальные имена/новости/медиа — только из данных команды/Supabase.
- Язык мира, не корпоративный. Одно главное действие на экран.
- Результат → `design/game-core/` в ветке `content/game-core-20261028`, PR в `design/launch-ui-v1-20261028`.

После твоих текстов я подставлю их в `launch-ui/*` (убрав шаблоны «Имя Фамилия» / «Название проекта») и подключу реальные данные из Supabase к размеченным `DATA:` слотам — это и будет «полностью загруженная» живая платформа.
