# TRIZNES · WORLD DESIGN SYSTEM

## Принцип

Одна реальность, одно ЯДРО, две игровые оптики. РАЙ и CYBER никогда не являются двумя наборами акцентных цветов на одном экране. В каждый момент интерфейс имеет один активный визуальный язык.

ЯДРО — общий нейтральный слой: графит + холодный сапфировый свет + белый. Оно не принадлежит ни РАЮ, ни CYBER и не использует их вторичные акценты одновременно.

## РАЙ

Смысл: изобилие, человеческое тепло, свет, связь, природа, красота, раскрытие.

Палитра:
- background: `#07110c`
- mint: `#78e1bd`
- gold: `#e8c879`
- ivory: `#fff8e8`
- green support: `#8cbd8a`

Запрещено в декоративном слое РАЯ:
- magenta / hot pink
- electric violet
- холодные cyber-grid свечения

Форма:
- крупнее радиусы
- мягкие органические radial gradients
- рассеянное свечение
- меньше сетки, больше воздуха

## CYBER

Смысл: задача, маршрут, интерфейс, контраст, система, скорость, измеримый шаг.

Палитра:
- background: `#02040c`
- electric cyan: `#35e9ff`
- electric blue: `#2877ff`
- violet: `#8058ff`
- magenta: `#ff2ec8`

Запрещено в декоративном слое CYBER:
- тёплая золотая заливка
- mint / botanical green как основной акцент
- кремовые/ivory поверхности

Форма:
- меньшие радиусы
- жёсткая геометрия
- grid / line structure
- локальное электрическое свечение

## REAL / FACT

Переключение РАЙ/CYBER никогда не меняет факты, координаты, личности, права, consent state, provenance или источник медиа. Оно меняет только художественную оптику и игровой интерфейс.

`REAL / AI ASSISTED / GENERATED / ARCHIVE` остаются provenance-метками, а не частью палитры мира.

## Карта

REAL-карта одна. РАЙ и CYBER используют те же точки и данные.

РАЙ:
- линии mint → gold
- мягкий тёмно-зелёный фон
- органическое свечение

CYBER:
- линии blue/violet/cyan/magenta
- холодный grid
- электрические маркеры

## Состояние

Активная оптика хранится в `localStorage` ключом `triznes-world-lens-v2` и применяется на всех Launch UI экранах.

Основные файлы:
- `world-themes.css` — токены и базовые правила
- `world-themes-polish.css` — изоляция от старых hard-coded visual-v4 цветов
- `world-themes.js` — переключение, persistence, map recolor, browser chrome

## Неподвижное правило

Если новый компонент одновременно использует насыщенный mint/gold и saturated cyan/violet/magenta — компонент нарушает канон и должен быть переработан.
