## По приоритетам

**1. Портреты только по проверенному slug.** Удалена карта `PHOTO_BY_INITIALS` и обе ветки подстановки по инициалам. Теперь портрет подставляется только на элементе с точным `data-character`, который есть в `PHOTO_BY_SLUG` (daniel / liberty / vsevolod[-kim]). Неизвестный slug (на `entry.html` есть карточка `data-character="neo"`) остаётся с placeholder/инициалами. Проверено: `strayFaceOnMonogram=false`, ни одного лица на монограмме по инициалам, `neo` без портрета.

**2. Неподтверждённые данные убраны из статической разметки.** `home.html` и `character.html`: сняты `PLAYER 001`, `@PLAYER 001` → `@псевдоним`, номера и даты глав («Глава 2 из 6», «Глава 3 · с октября 2026», месяцы в таймлайне), «Заполнено 4 из 5 граней» + 80% прогресс → пустое состояние, выдуманный «7 движений рядом» → нейтрально; классы прогресса (`done/current/locked`) с таймлайна сняты. Авторитетные поля по-прежнему наполняет адаптер из Supabase RPC. Важно: `@PLAYER 001` и чип «PLAYER 001 · профиль мира» на отрендеренной странице приходят из **бэкенда** (`alias` и `card_label` профиля), а не из разметки — это авторитетный источник, его я не трогал. Регекс выбора чипа в адаптере подправлен под новый текст, иначе тариф карты перестал бы гидратироваться.

**3. «Изобилие» — свои природные токены.** Дневную тему целиком задаёт `paradise-neon-v2.css` (грузится раньше v5). Реальный зазор: универсальное холодное стекло v5 затрагивало `.kpi/.sigcard/.step/.bezliki`, которых нет в селекторе paradise-neon-v2 — они проваливались в тёмное неоновое стекло. Дал им дневные токены темы; за общие панели и атмосферу с авторитетным правилом не конкурирую. «Игра» (cyber) сохраняет неоновый контраст. Проверено computed-стилями: Изобилие `.panel` = `rgba(255,255,255,.92)`, `.bezliki` = `.86` (был `.07`); Игра — `.07` + циан-бордер.

**4. Декоративная нагрузка.** Canvas-частицы встают на паузу в скрытой вкладке (`visibilitychange` + `cancelAnimationFrame`). Hover-glow навешивается только при `(hover:hover) and (pointer:fine)`. На тач (`@media (hover:none)`) снят hover-transform с карточек/кнопок/аватаров/маркеров — не залипает и не режет свайп-карусели; тени оставлены. `prefers-reduced-motion` уважается (как было).
