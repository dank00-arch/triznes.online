## 3. Права и редакционный процесс

| Роль | Смотреть | Приватно передать видео | Претендовать на выпуск | Опубликовать |
|---|---|---|---|---|
| Зритель без входа | Да | Нет | Нет | Нет |
| Авторизованный игрок | Да | После подтверждения серверной сессии | Нет до активной BLACK | Нет |
| Оператор с действующей BLACK | Да | Да | Да, с проверкой прав и согласий | Нет |
| Основатель / делегированный модератор | Да | Да | Да | Только после собственной авторизации и документированной проверки |

Пайплайн: вход → приватный upload в случайный путь → приём \`submitted\` → проверка исходника, прав, согласий, качества, маркировки, повторов → проверка действующей BLACK → отдельное решение основателя → \`published\` → только тогда добавление фильма в общедоступный 24/7 playlist. Отзыв согласия должен переводить опубликованный файл в \`withdrawn\` и удалять его из программы.

**Карта не даёт автоматического права публикации.** Права у проверенного оператора ограничены отправкой на рассмотрение. Бэкенд не должен принимать \`player_id\`, \`tier\`, \`is_admin\` от клиента как основание для прав.
