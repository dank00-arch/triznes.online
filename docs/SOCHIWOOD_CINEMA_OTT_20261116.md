# SOCHIWOOD CINEMA — первый OTT-релиз
Дата: 16 ноября 2026. Путь зрительского кинотеатра: `/launch-ui/cinema-24-7.html`.

## Дизайн, источник и ограничения
Визуальный канон — действующая нейроферма TRIZNES (фиолетово-розово-голубое неоновое ядро, графитовые полупрозрачные поверхности, крупные кинематографичные карточки персонажей, микротипографика).
В основу UX-подхода взяты общие идеи OTT-сервисов — главный фильм, ряды подборок, категории, поиск, избранное, просмотр, «следующий фильм». Чужая фирменная айдентика, логотипы и дизайн-код Иви или Okko не копируются.

## Публичная поверхность
- Бренд: **SOCHIWOOD CINEMA**, кредит TRIZNES × PINK NOIZE Production.
- Hero full-width с кадром подлинного опубликованного фильма о Сочи, градиентная типографика, две главные CTA («Смотреть», «Каталог») и «В избранное».
- Каталог по коллекциям, фильтры/поиск, горизонтальные ряды, карточки с реальными обложками опубликованных роликов, избранное в локальном браузере.
- Иммерсивный 16:9 плеер YouTube, следующий/предыдущий фильм, автоматическое продолжение после финала в поддерживаемом Iframe API, внешняя ссылка на YouTube при ограничениях встраивания.
- Mobile first: горизонтально прокручиваемые категории, адаптивные обложки, крупные кнопки просмотра, скролл-карточки, поддержка reduced-motion.
- **Никакой имитации LIVE, никаких фраз про режим регистрации/входа на витрине**. Этот PR не включает студию операторов.

## Структура для переноса на отдельный хостинг
Самостоятельное статическое ядро, состоящее только из 3 файлов:
1. `cinema-24-7.html` → на новом домене переименовать в `index.html`;
2. `sochiwood-cinema.css`;
3. `sochiwood-cinema.js`.

Внутренние ссылки CSS/JS — относительные к HTML, поэтому их можно перенести вместе без сборщика. Шрифты загружаются из Google Fonts с системными fallback. Постеры — с YouTube, фильмы — с официального YouTube через Iframe API. Ключи, пароли и служебные API не используются. Избранное сохраняется локально для браузера и на новом домене начнётся отдельно.

После отдельного согласования хостинга: перенести пакет, настроить DNS, SSL, CSP с youtube.com/youtube-nocookie.com/i.ytimg.com/fonts.googleapis.com/fonts.gstatic.com, кеширование CSS/JS, перенаправление со старого адреса и мониторинг ошибок.

## QA перед внешней рекламой
1. iPhone Safari и Android Chrome: горизонтальное меню, поиск, избранное с каждого фильма, fullscreen player, X и Escape.
2. iOS autoplay ограничен платформой: после нажатия «Смотреть» пользователь может дополнительно нажать Play в плеере.
3. Если YouTube блокирует iframe — всегда доступна кнопка «YouTube».
4. Редакционная защита: видео, требующие отдельного согласования, не попадают в программу, пока нет подтверждения.
5. На каждой странице не писать «прямая трансляция» или «LIVE» при показе записанных видео.
6. Не менять авторизацию, PIN, BLACK CARD, RLS или права на публикацию этим визуальным PR.
