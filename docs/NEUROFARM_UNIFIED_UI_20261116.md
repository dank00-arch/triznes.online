# TRIZNES × NEUROFARM — единая визуальная система
Обновление: 16 ноября 2026.

## Источник, не вымышленный референс
Основа взята из действующего кода Edge Functions проекта TRIZNES DANIEL: `neurofarm-member-app` (члены, персонажи, ежедневный путь, Аполлон) и `neurofarm-member-web` (центр управления). Код визуального слоя проверен через подключённый Supabase. Нет копирования прав доступа, приватных сведений игроков или административных ключей.

## Токены
- BG `#07060b`; panel `#11101a`; panel2 `#171522`
- PINK NOIZE `#ff3cc7`, CYAN `#42efff`, VIOLET `#9c72ff`, GOLD `#ffd66b`, LIME `#caff39`
- CTA: `linear-gradient(115deg, pink, violet, cyan)`
- Кино: горизонтальный плеер 16:9, стеклянная рамка, превью реальных выпущенных YouTube-роликов, компактная программа, честный статус «архивный цикл / НЕ LIVE»
- Персонажи: сохранение реальных лиц и существующих карточек, единая палитра, без подмен или генерации чужих лиц
- Клубная карта: золото остаётся статусным цветом, не выдаётся через CSS или фронтенд

## Что изменено
- `launch-ui/neurofarm-unified.css` — единый визуальный слой, мобильная адаптация iPhone/Safari, reduced motion, шрифты из существующих ресурсов репозитория.
- `launch-ui/cinema-24-7.html` — героический блок нейрофермы, визуальная дорожка создания кино, обложки программных YouTube-выпусков, сохранение состояния звука, прямые ссылки на видео при блокировке встраивания, статус камеры без имитации LIVE.
- `launch-ui/entry.html` — единый стиль CTA и входа.
- `launch-ui/home.html` — единый стиль домашнего экрана и входа в кино.
- `app/index.html` — единый стиль карты/ленты, карта кинотеатра в ленте без изменения JS-логики входа.
- Студия операторов отдельно оформлена тем же стилем в **draft PR #41**. Её серверную часть не включать до безопасной привязки сессий и BLACK CARD.

## Гарантии
- Настоящая городская LIVE-камера не подключена; архив обозначен честно.
- Нельзя загружать ролики в публичную часть через фронтенд без серверного подтверждения карт, исходников, прав участников и решения основателя.
- Нет изменений в Supabase, пользовательских PIN, RLS, карточках или оплаченных услугах.
- Для визуального релиза допустим merge в main независимо от серверной студии.

## Приёмочные проверки
1. Cinema: autoplay muted, следующий ролик, сохранение настройки звука, YouTube fallback, iPhone Safari.
2. Стили: русские и английские заголовки, адаптивность 320–430px, desktop, reduced-motion.
3. Entry/home/app: авторизация персонажей, маршрутизация, чат, карты, API без изменений.
4. Студия операторов: закрыта до отдельного тестового внедрения, никакого ложного статуса «публикация разрешена».
