# SOCHI MATRIX → ядро TRIZNES · разбор и внедрение
2026-11-12 · Claude · источник: архив Аргона `SOCHI_MATRIX_TRIZNES_CORE.zip` (16 файлов, оригинал сохранён в `archive/argon-sochi-matrix-20261112/`).

## Что сделано (проверено)
- `app/matrix/` — 3D-Сочи «Два мира» на Three.js: 9 119 реальных зданий с высотами, вода, улицы и парки центра Сочи (OpenStreetMap через OpenFreeMap, снимок 01.11.2026). Режимы РЕАЛЬНЫЙ / СИНТЕЗ / МАТРИЦА, лучи узлов по ступеням, силовые дуги, проводники ядра, персонажи ядра, лента, дальние точки (Мамайка, Дагомыс, Ахун, Красная Поляна).
- Кнопка «2М» на экране «Город» приложения v2 ведёт в `app/matrix/`.
- Координаты узлов сверены с базой `triznes_world_places` (только чтение) и OSM.
- Проверено в Chromium: десктоп 1280×800 и телефон 390×844, ошибок в консоли нет.
