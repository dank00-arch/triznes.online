# TRIZNES · единое приложение (`unified/`)

Одно приложение вместо разрозненных экранов: лента **SOCHIWOOD 24/7** (Солнце), персонажи и **резонанс**, совет проводников, путь творца, город, Нейроферма. Чистый HTML/CSS/JS без сборки и внешних библиотек.

## Что работает только на устройстве (сервер ещё не готов)

Профиль гостя, отклики и веса интересов, резонанс, «в резонансе», мои посты, диалоги, отметки согласий, отметки уровней, заявки Нейрофермы. Всё хранится в `localStorage` (`triznes-unified-v1`) и никуда не отправляется. Статусы серверных возможностей — в «Настройках» приложения и в `dank00-arch/TRIZNES: docs/IMPLEMENTATION_STATUS.md`.

- **Резонанс** — косинусная близость моих весов и направлений, взятых из собственных слов персонажа (роль, идея, мечта). Объясним: экран показывает «что общего». Это предварительный расчёт на устройстве, не серверный подбор.
- **Отражение** (шесть блоков) строится только про самого пользователя и только из его действий. О других людях приложение выводов не делает.
- **Проводники** без шлюза отвечают по прошивке и действиям пользователя, без нейросети: АПОЛЛОН ведёт вопросы входа, ДИОНИС даёт текущий уровень, BEZLIKI — один следующий шаг, ЧИВУРУНДУ знакомит с персонажем, TRIZNES ASSISTANT отвечает фактами о состоянии проекта. Маршрут между ними — по словам-намерениям из реестра.

## Структура

```
index.html        каркас
css/app.css       стили и токены двух оптик
js/seed-world.js  уровни, места, проводники (из прежнего app/data/world.json)
js/seed-cast.js   канон, миры, персонажи, нейроперсонажи, публикации, новости, карты, согласия
js/core.js        состояние, резонанс, образ персонажа, небо, слой API
js/app.js         экраны, маршруты, действия
tools/bundle.py   сборка в один HTML-файл для предпросмотра
matrix/           Сочи 3D · Два мира
media/            видео и подкасты проекта
```

Экраны (hash): `sun`, `me`, `bonds`, `dialogs`, `signals`, `p-<slug>`, `r-<slug>`, `w-<slug>`, `n-<нейроперсонаж>`, `chat-<проводник>`, `talk-<персонаж>`, `path`, `city`, `farm`, `worlds`, `cards`, `consents`, `saved`, `prefs`.

## Запуск

```bash
python3 -m http.server 8080
```

Запускать из корня репозитория; открыть `http://localhost:8080/unified/`. Один файл для пересылки:

```bash
python3 unified/tools/bundle.py triznes-unified.html
```

## Подключение сервера

Адрес и публичный ключ сервера чтения задаются в `TZ.config.stage` при развёртывании; в репозитории они пустые. Личные операции подключаются только через единый шлюз по контракту `docs/openapi.yaml` (репозиторий `dank00-arch/TRIZNES`).
