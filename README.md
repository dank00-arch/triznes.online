# TRIZNES — единая папка проекта

Это компактная копия исходников сайта и Telegram-бота, подготовленная для передачи и аудита.

## Структура

- `website-platform/` — сайт, API/backend, ресурсы, Supabase-схема и миграции. Главный файл сайта: `website-platform/index.html`.
- `website-platform/legacy/triznes-github/` — уникальные файлы прежней версии, сохранённые отдельно для справки; не запускайте их вместо основной платформы без проверки.
- `telegram-bot/` — отдельный проект Telegram-бота с инструкциями, `.env.example` и миграциями, относящимися к боту.
- `../TRIZNES-GOOGLE-DRIVE-CONTENT/` — вынесенные видео и аудио; внутри сохранены прежние относительные пути, например `website-platform/assets/`.
- `../TRIZNES-LOCAL-CONFIG/` — локальные `.env` с настройками; не включать эту соседнюю папку в архив или передачу ChatGPT.

Сайт и бот сохранены как отдельные части: у них разные процессы запуска и настройки. Не заменяйте backend сайта файлами бота без отдельной проверки. Сборки, кэши, зависимости и крупные медиа в этой папке не хранятся.

## Запуск для разработки

1. Для API сайта перейдите в `website-platform/backend/` и создайте `.env` на основе `.env.example`. Если нужны сохранённые локальные настройки, из корня проекта скопируйте `../TRIZNES-LOCAL-CONFIG/website-platform-backend.env` в `website-platform/backend/.env`. Затем выполните `npm install` и `npm start`.
2. Для Telegram-бота перейдите в `telegram-bot/`, скопируйте `.env.example` в `.env`, заполните настройки и выполните `npm install`, затем `npm run bot`.
3. Перед применением SQL-файлов проверьте соответствующие README и применяйте миграции к правильному проекту Supabase в указанном там порядке.

После перемещения медиа локальные ссылки сайта `/assets/...` не будут открываться, пока соответствующие файлы не будут подключены с Google Drive через подходящие публичные URL/хранилище/CDN либо временно возвращены по прежним путям. Папка Google Drive сама по себе не меняет ссылки сайта.

Локальные `.env` сохранены отдельно с закрытыми правами доступа; не публикуйте их и не отправляйте в чат. Папки `node_modules` не копировались: зависимости устанавливаются командами `npm install`.

## Перед удалением старых копий

Перед публикацией сначала подключите медиа и проверьте сайт, API и бота. Сохраняйте отдельную резервную копию исходников и медиа.
